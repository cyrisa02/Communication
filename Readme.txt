Utilistion de Cute PDF Writer


Configurer le format dans les paramètres de l'imprimante Windows

    Ouvrez le menu Démarrer de Windows, accédez à « Périphériques et imprimantes » (ou « Imprimantes et scanners »).

    Trouvez « CutePDF Writer », faites un clic droit et sélectionnez « Préférences d'impression » (ou « Propriétés de l'imprimante »).

    Dans la fenêtre qui s'ouvre, cliquez sur le bouton « Avancé ».

    Dans la liste déroulante « Taille du papier », sélectionnez « PostScript Custom Page Size » (Format de page personnalisé PostScript).

    Saisissez vos dimensions : Largeur 91 mm, Hauteur 61 mm (si le système demande des centimètres, saisissez 9,1 et 6,1), puis cliquez sur OK pour fermer les fenêtres.

Étape 2 : Revenir dans Chrome pour imprimer

    Retournez dans la fenêtre d'impression de Chrome (si vous l'avez fermée, appuyez à nouveau sur Ctrl + P).

    Assurez-vous que la destination est bien « CutePDF Writer ».

    Cette fois, dans la liste déroulante « Taille du papier », vous devriez voir l'option « PostScript Custom Page Size » que vous venez de créer (si elle n'apparaît pas, rafraîchissez la page ou redémarrez Chrome).

    Sélectionnez-la, vérifiez que l'aperçu à gauche montre une carte qui remplit toute la page, puis cliquez sur « Imprimer » et enregistrez le fichier.

Une fois le PDF enregistré, ouvrez-le et vérifiez qu'il contient bien 2 pages et que le fond noir s'étend jusqu'aux bords, vous pourrez alors l'envoyer à l'imprimeur.
